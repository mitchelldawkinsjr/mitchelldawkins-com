Sports Box is a multiview dashboard for watching several live streams in one Chrome window.

![Sports Box demo: six panels in Wide, then 1+N with four, Solo, and Showtime](/images/projects/sports-box/demo.gif)

The build notes are on the [Sports Box project page](/projects/sports-box).

Paste a stream URL into a panel. Spectrum, YouTube, Twitch, Vimeo, HLS (`.m3u8`), and other pages you already have access to can sit in a grid from 1 to 16. Mute, volume, and Solo are per panel. Fill video crops the panel to the player. Named layouts save a slate and load it again. Watch mode hides the URL bars.

The toolbar icon opens the dashboard. No separate server is required for the wall itself.

An optional phone remote, on the same Wi-Fi, can change solo, volume, and the grid. Scores for the leagues you turn on load from public scoreboard feeds. An optional CollegeFootballData key stays on your computer.

The extension does not ask for an account. Layouts stay in this browser. Nothing is sent to the developer.
