## Introduction

**Little Sprouts** is a static browser app of early-learning games. A learner picks a card, hears the prompt, and answers. Grown-ups set the math band, each game’s level, and the sight-word list in Parent corner.

**Source:** [mitchelldawkinsjr/little-sprouts](https://github.com/mitchelldawkinsjr/little-sprouts)

For the product story, see [Little Sprouts: Play That Teaches](/blog/little-sprouts-play-and-learn).

**Status: Active** — play it from the repo with a static file server. There is no account and no build step.

## Problem & Solution

### The Problem

- **One shared profile** mixes up siblings’ words and scores
- **Screen-only play** leaves out kids who need to move
- **A new app per skill** means a new login, a new progress store, and a new voice
- **Borrowed game ideas** disappear into the code unless someone writes them down

### The Solution

1. **A learner profile** — name, buddy, math band, levels, sight words, and stars in `localStorage`
2. **Four play styles** — Tap, Move, Hunt, and Reach, on the same questions
3. **One shelf** — shapes, colors, words, counting, and arcade games read that profile
4. **A static folder** — `python3 -m http.server` is the whole deploy
5. **A credits list** — on the site and in the README, with links

## Run it

From the repo:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

| Piece | Choice |
|-------|--------|
| UI | `index.html`, `style.css`, one module per game |
| State | `localStorage` on this browser |
| Speech | Kokoro in a worker, browser voice as fallback |
| Reach | MediaPipe Pose, loaded on first use, video stays local |
| Questions | `sheet.csv`, with an optional published Google Sheet |
| Tests | `node --test logic.test.mjs` and `camera.test.mjs` |
| Hosting | Any static host. No server runtime |

## Play styles

| Style | Child | Grown-up |
|-------|-------|----------|
| Tap | Taps the answer | Optional |
| Move | Moves to a printed floor card | Taps when they land |
| Hunt | Finds a real object that matches | Confirms |
| Reach | Holds a hand on the answer | Allows the camera once |

Move and Hunt do not rewrite the arcade games. Those stay on the screen. Reach changes Catch the answer, Word lanes, and Hook the fish.

## What the shelf is made of

Learning cards (Shape safari, Color garden, Word parking, Count & clap, Number path) render choices in the page. Arcade games draw on canvas or in their own page: Moon shot, Gas race, Hook the fish, Sky shot, Garden chase, Dirt ride, Sky flight, Paint sphere, and the rest of the shelf.

Sky flight and Paint sphere use Three.js. Garden walk uses BlocksJS for the canvas and the walk. Dirt ride is its own canvas bike. Backroad rally’s stage files are large and are not in the GitHub repo, so that card stays hidden unless those files are added locally.
